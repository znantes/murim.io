# Murim — immersion, relations et portraits

## Immersion
- Interface contextuelle : afficher d'abord ce que le personnage peut réellement percevoir.
- Ambiance locale : météo, heure, foule, sons textuels, odeurs, lumière, état des routes.
- Présence physique : position, distance, direction, posture et activité des personnes rencontrées.
- Informations partielles : aucune omniscience gratuite ; les faits inconnus restent inconnus.
- Continuité : les conversations, promesses, dettes, blessures et rumeurs réapparaissent plus tard.
- Mode immersion : réduire les panneaux techniques et privilégier la chronique, le lieu et les personnes présentes.

## Relations
Chaque relation doit être multidimensionnelle :
- confiance ;
- affection ;
- respect ;
- peur ;
- dette ;
- rivalité ;
- loyauté ;
- connaissance réelle de l'autre.

Les relations évoluent selon les actions, le temps, les témoins, les rumeurs et la mémoire. Une relation n'est pas un simple nombre.

## Portraits
Le portrait est une identité visuelle persistante :
- identifiant stable du PNJ ;
- sexe et âge ;
- vieillissement ;
- traits visibles ;
- cicatrices et blessures ;
- statut et métier ;
- appartenance familiale ou sectaire ;
- vêtements et contexte régional.

Un même PNJ doit garder une identité reconnaissable à travers ses différents âges. Les portraits ne doivent pas être partagés arbitrairement entre deux PNJ importants.

## Cache et performances
- Générer/charger seulement les portraits nécessaires à l'écran.
- Précharger les personnages proches et les portraits fréquemment consultés.
- Utiliser des tailles adaptées : miniature, fiche, grand portrait.
- Conserver les métadonnées séparément des images.
- Ne jamais charger des milliers d'images simultanément.

## Idées de systèmes futurs
- expressions dépendant de l'état émotionnel ;
- vêtements qui changent avec métier, saison et statut ;
- cicatrices persistantes ;
- portraits de groupe pour familles/sectes ;
- reconnaissance visuelle approximative par les PNJ ;
- portrait enfant → adulte → ancien ;
- portrait dégradé/ancien pour souvenirs et archives ;
- portrait masqué ou caché lorsqu'une identité secrète est inconnue.
