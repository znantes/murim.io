# Assets visuels du monde

Ce dossier accueillera les illustrations finales des lieux. Le moteur génère les chemins attendus via `WorldIllustrationCatalog`.

Ne pas copier directement des images trouvées sur Internet dans le jeu final sans licence compatible. Les références visuelles servent à la direction artistique ; les assets distribués avec le jeu doivent être originaux ou correctement licenciés.

Format recommandé : WebP, ratio principal 16:9 ou 3:2 selon la scène, avec une version `default.webp` obligatoire pour les lieux uniques quand leur illustration est produite.

Variantes facultatives : `spring_day_clear.webp`, `summer_dusk.webp`, `winter_night_snow.webp`, etc. Le résolveur retombe automatiquement vers une variante plus générale puis `default.webp`.
