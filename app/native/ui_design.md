# Murim — direction visuelle

L'application native adopte une interface de RPG/gestion du Jianghu :

- barre supérieure : ère, date, temps, ressources, sécurité ;
- colonne personnage : portrait, âge, statut, corps, esprit, Qi, attributs ;
- centre : illustration du lieu actuel, carte et chronique ;
- panneau actions : cultiver, étudier, explorer, travailler, observer, attendre ;
- panneau Jianghu : événements, personnes connues, relations, rumeurs, économie, organisations ;
- panneaux inférieurs : techniques, manuels, inventaire, compétences, secrets, classement ;
- portraits chargés à la demande et liés à l'identité/âge du PNJ.

Les données doivent rester séparées de l'interface et être chargées progressivement.
