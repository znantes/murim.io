# Archive — fichiers inutilisés

Ce dossier contient les anciennes versions conservées pour référence et récupération éventuelle.

Les fichiers de ce dossier ne sont jamais chargés par le jeu principal.

Organisation prévue :
- archive/legacy-game/ — anciennes versions du jeu
- archive/legacy-ui/ — anciennes interfaces
- archive/legacy-tools/ — anciens outils de test

Les nouveaux systèmes actifs doivent rester dans les dossiers actifs du projet.
