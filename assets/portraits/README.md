# Murim — Portraits

Bibliothèque de portraits externes au moteur. Les portraits ne sont jamais compilés dans `Murim.exe`.

Convention recommandée : `P000001/age_00.webp`, `age_05.webp`, `age_12.webp`, `age_18.webp`, `age_30.webp`, `age_45.webp`, `age_65.webp`.

Le moteur utilise `data/portraits.json` pour relier une identité persistante à ses variantes d'âge et d'état.
