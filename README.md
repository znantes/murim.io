# Murim — Les Mille Destins

Site web autonome pour présenter et lancer le jeu.

- `index.html` : page d'accueil
- `jeu.html` : version du jeu intégrée
- `jianghu-preview.png` : visuel de présentation

Pour tester localement : ouvrez `index.html` dans un navigateur moderne.
Pour publier : envoyez le contenu du dossier sur un hébergeur statique (Netlify, GitHub Pages, etc.).
